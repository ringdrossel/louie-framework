Game-profile recipes: Godot project skeleton, Dialogue Manager, SpriteCook asset pipeline, content-integrity audit.

These recipes belong to LOUIE's **game profile** (`louie-profile game`). Each one declares `**Requires profile:** game`; `louie-recipe` warns before loading one into a `standard` project.

They are the only place where engine-, addon-, and tool-specific guidance lives — the game agents and overlays stay engine-agnostic. Every version number and command in these recipes is cited with its source and the date it was verified. Versions move: before applying a recipe, re-check the cited sources and update the recipe if they changed.
